# Inventory Reservation Service

A Java/Spring Boot portfolio backend for concurrent inventory reservations, order lifecycle transitions, and reliable event delivery.

## Implementation plan

Each stage is tested before its commit. See [docs/implementation-plan.md](docs/implementation-plan.md).

## Toolchain

- Java 21
- Spring Boot 3.5.16, Maven
- PostgreSQL (production and integration tests); H2 is only a fast local test profile

This repository is under active construction. Features and test evidence are recorded as they are implemented.
